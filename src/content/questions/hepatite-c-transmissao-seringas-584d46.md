# Content

> A hepatite C é uma doença hepática causada pelo VHC. A hepatite C pode variar de uma doença leve, com duração de algumas semanas, a uma doença grave e de longa duração. A hepatite C é um dos tipos mais comuns de hepatite viral nos Estados Unidos. Em 2022, pessoas com idades entre 20 e 39 anos apresentaram a maior incidência de hepatite C aguda.
>
> (www.cdc.gov. Adaptado.)
